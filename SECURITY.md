# Security Policy

## Reporting a Vulnerability

Security is paramount to Infernos. If you discover a security issue or vulnerability concerning L402 payment verification, macaroon validation, or sensitive data leakage:

1. Please do not open a public issue.
2. Email security concerns to `hamza.00dev1@gmail.com` or submit a private GitHub security advisory.
3. We will respond promptly with an acknowledgment and mitigation timeline.
